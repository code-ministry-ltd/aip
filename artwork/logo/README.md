# AIP logo assets

The selected orange orangutan and lowercase `aip` lockup, with black glasses.

## Files

- `aip-logo-transparent.png` — full-color horizontal lockup with transparent background (master raster, 1774 px wide).
- `aip-logo-white-background.png` — convenience export for documents and light surfaces.
- `aip-mark-transparent.png` — ape mark only, transparent 1024 × 1024 PNG.
- `aip-app-icon.png` — square app icon on warm white; do not add another background.
- `aip-icon-512.png`, `aip-icon-256.png`, `aip-icon-128.png`, `aip-icon-64.png` — transparent square mark exports.
- `apple-touch-icon.png` — 180 × 180 transparent mark export.
- `favicon.ico` — 16, 32, and 48 px mark sizes.

The artwork is currently a high-resolution raster PNG, not a vector master. For print or very large-format use, the logo should be redrawn as a true vector before delivery.
